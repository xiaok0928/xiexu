## 目录说明

- `visual-guidelines.md`：视觉方向、色板、字体、间距、图标与响应式原则。
- `specs.md`：页面规格、状态约定、核心交互、交付范围外内容。
- `pages/`：可直接浏览的静态交互 HTML 设计包。

## 批准流程

1. UI 先完成静态设计包。
2. 交给 PM 评审。
3. PM 通过后，即视为 UI 门禁通过。
4. 不再等待用户对 G0 设计包做额外确认。

## 设计约束

- 不改源码。
- 不引入新产品语义。
- 不做营销页。
- 不做大圆角、渐变装饰、卡片套卡片。
- 任务面板、项目空间、工作流、新对话、Agent、设置、运行记录共享同一事实源语言。
