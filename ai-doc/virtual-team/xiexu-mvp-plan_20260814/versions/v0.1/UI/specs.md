# 协序 MVP UI 规格说明

日期：2026-08-14
版本：v0.1

## 1. 设计目标

将协序 MVP 的核心能力压成一个可直接浏览的 Web 工作台原型：
- 任务面板作为主入口。
- 项目空间承接研发上下文。
- 工作流画布承接自动化编排。
- 新对话承接 Human 与单 Agent 的单人交互。
- 运行记录承接执行证据。

## 2. 信息结构

### 一级模块
- 任务面板
- 项目空间
- 工作流
- 新对话
- Agent
- 运行记录
- 设置

### 二级核心对象
- Task
- Project
- Workflow
- WorkflowRun
- Agent
- Comment
- RunOutput
- Setting

## 3. 状态约定

### 任务阶段
- `backlog`：只记录想法，不执行
- `todo`：已确认，等待协调
- `plan_review`：方案待确认
- `in_progress`：处理中
- `acceptance`：等待验收
- `done`：归档 / 完成
- `cancelled`：取消

### 执行状态
- `queued`
- `running`
- `blocked`
- `failed`
- `succeeded`
- `cancelled`

### 工作流状态
- 草稿
- 已保存
- 运行中
- 暂停
- 终止
- 历史版本

## 4. 页面规格

### 4.1 任务面板

布局：
- 左侧：固定看板列。
- 右侧：任务详情抽屉。

关键交互：
- 任务卡点击后在右侧显示详情。
- Todo 卡片提供默认勾选的“方案确认”入口。
- 父任务可展开/收起子任务。
- 评论驱动验收成功、验收失败、返工、补充意见。

### 4.2 项目空间

布局：
- 主区：项目概览、群聊、任务、文档。
- 侧区：项目文档版本、刷新记录、Agent 关系。

关键交互：
- 群聊可生成任务。
- 父任务完成后可触发文档刷新。
- 任务与项目共享同一事实源。

### 4.3 工作流

布局：
- 左：工作流列表。
- 中：画布。
- 右：属性面板与运行配置。

关键交互：
- 节点拖拽。
- 连接线标识 `是 / 否`。
- 人工确认节点通过评论语义处理。
- 运行时锁定当前版本。

### 4.4 新对话

布局：
- 左：会话列表。
- 中：对话流。
- 右：当前 Agent 与上下文。

关键交互：
- 仅 Human + 单 Agent。
- 可从对话发起任务草稿。

### 4.5 Agent

布局：
- 卡片式身份列表。
- 详情说明职责、记忆、关联项目。

关键交互：
- 默认角色可作为创建模板。
- 自定义 Agent 可附加特定职责。

### 4.6 运行记录

布局：
- 列表 + 详情时间线。

关键交互：
- 可回看任务、工作流、节点、输出。

## 5. 交付范围外

- 权限管理页
- 外部注册页
- 批量暂停 / 批量终止
- 复杂规则引擎可视化
- 桌面端专属交互
