# 协序 MVP UI 视觉指南

日期：2026-08-14
版本：v0.1

## 1. 视觉方向

目标不是做“漂亮后台”，而是做“安静、高密度、可扫读的工作台”。

风格原则：
- 背景浅灰，内容白底，强调区域层次而不是装饰。
- 低圆角，低阴影，少渐变，少浮夸动效。
- 强调状态色、来源色、执行色，弱化无关插画。
- 像任务系统，不像营销页。

## 2. 色彩

推荐色板：
- `Text / 主文本`：`#22272e`
- `Muted / 次文本`：`#6b7280`
- `Surface / 卡片底`：`#ffffff`
- `Surface Soft / 浅底`：`#f9fafb`
- `Border / 描边`：`#dfe3e8`
- `Primary / 任务与动作蓝`：`#3b73f6`
- `Success / 执行成功绿`：`#2f9e62`
- `Warning / 等待确认橙`：`#d97706`
- `Danger / 终止或失败红`：`#dc3545`
- `Support / 工作流紫`：`#7c3aed`

状态色使用规则：
- 阶段状态优先用标签，不直接用大面积底色。
- 执行状态优先展示在进度条、徽标、时间线和运行记录里。
- 同一块区域不同时放超过 2 种强状态色。

## 3. 字体

推荐：
- 中文：系统字体栈优先。
- 英文与数字：系统等宽/半等宽在代码、ID、路径、hash 上使用。

字号建议：
- 页面标题：18–22px
- 卡片标题：14–16px
- 正文：13–14px
- 辅助信息：11–12px

## 4. 间距与形状

- 页面内边距：10–16px。
- 卡片内边距：10–14px。
- 模块间距：12px。
- 圆角：6–8px，避免大圆角。
- 阴影：轻微即可，不能抢层次。

## 5. 图标

- 使用熟悉、直观、低干扰的图标。
- 图标只辅助识别，不替代文字。
- 顶部操作区、导航、状态徽标、工作流节点都需要图标，但密度要克制。

## 6. 组件密度

任务卡片优先展示：
1. 任务标题
2. 任务 ID / 来源
3. 阶段或执行状态
4. 所属项目 / Agent
5. 父子关系 / 进度

不要让卡片成为“信息拼盘”。

## 7. 响应式策略

- 桌面优先，宽屏完整。
- 中屏压缩侧栏，保留看板横向滚动。
- 窄屏只保证查看与单列操作，不承诺完整画布编排体验。
